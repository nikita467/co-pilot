# Ко-Пилот

Фронтенд платформы «Ко-Пилот»: ИИ-ассистент, агенты и каталог ИИ-сервисов для продуктовых команд.
Интерфейс построен на [Ant Design 5](https://ant.design/), React 18, TypeScript и Vite.

Сейчас это кликабельный прототип на демо-данных. Backend и подключение к LLM пока не реализованы:
ответы ассистента генерирует локальный mock в `src/services/assistant.ts`, а состояние хранится в `localStorage`.

## Быстрый старт

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production-сборка в dist/
npm run typecheck  # проверка типов
```

Нужен Node.js 18 или новее.

Сквозной сценарий из раздела 12 (падение конверсии на шаге «Ввод паспорта», PR #4521, инцидент INC-101) зашит в демо-данные. Его можно пройти от дашборда до задачи, диалога с ассистентом и базы знаний.

## Структура

```
src/
  App.tsx                 # ConfigProvider (тема, локаль) и маршруты
  layout/AppLayout.tsx    # шапка, сайдбар, глобальные модалки
  store/AppStore.tsx      # состояние приложения (React Context + localStorage)
  data/types.ts           # доменные типы
  data/mock.ts            # демо-данные
  services/assistant.ts   # mock-логика ассистента (заменить на API)
  components/             # графики, чат, уведомления, модалки
  pages/                  # страницы разделов
```

## Публикация на GitHub

```bash
git init
git add .
git commit -m "Ко-Пилот: прототип фронтенда на Ant Design"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/co-pilot.git
git push -u origin main
```

Workflow `.github/workflows/deploy.yml` сам соберёт проект и опубликует его на GitHub Pages
(в репозитории: Settings → Pages → Source: GitHub Actions). Используется `HashRouter`, поэтому
маршруты работают на Pages без дополнительной настройки.
